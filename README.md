# advanced-ragdoll

Rapier + three.js로 만든 웹 기반 액티브 랙돌(Euphoria 스타일) — 밀리고 맞고 넘어지고 일어서는 반응을 물리로 사람답게 시뮬레이션한다. 명세는 [SPEC.md](SPEC.md), 작업 규칙은 [CLAUDE.md](CLAUDE.md), 공개 API는 [docs/API.md](docs/API.md).

**웹 데모: https://junjun612.github.io/advanced-ragdoll/** (첫 로딩 약 16MB, 데스크톱 브라우저 권장)

## 실행 방법
```bash
npm ci
npm run dev          # 앱 (http://localhost:5173)
npm test             # 단위 테스트
npm run sim:all      # 전체 시나리오 → out/report.md
npm run film -- <시나리오>   # 필름스트립 → out/<시나리오>/
npx vite build       # 웹 데모 빌드 → dist/ (GitHub Pages 경로 /advanced-ragdoll/)
```

에셋: 캐릭터 X Bot은 [Mixamo](https://www.mixamo.com)(Adobe), 동작 클립은 Kimodo로 생성했다(`assets/poses`). Mixamo 애니메이션 파일은 쓰지 않으며 저장소에 넣지 않는다.

### 2026-10-26 v0.2 FBX 스킨 렌더 (결정)
- **스킨 rest = 랙돌 A포즈**: 본 월드 회전 = D_body · RestA_bone, D_body = Q_body · inv(restRotation). RestA_bone은 X Bot 바인드(T포즈)에 소속 바디 rest 회전을 어깨 피벗 중심으로 적용한 것(genRagdoll A포즈 변환과 같음). 바인드(T포즈)를 그대로 쓰면 rest 상태에서 메시 팔이 캡슐보다 60° 위에 뜬다. 대안: 바인드 자체를 A포즈로 다시 굽기(boneInverses 재계산, 복잡).
- **대표 본 위치는 바디에서 직접**(바디 위치 + D·(RestA_bone − restPosition)), 나머지 본은 부모에서 계층으로. 관절이 조금 늘어나도 메시가 캡슐에서 떨어지지 않는다.
- **흡수 본 보간**(`config/skin.json`): Spine·Neck은 양쪽 바디 Δ회전의 중간(0.5), 어깨는 0.25(쇄골이 팔을 조금만 따라감; 팔 본 위치는 바디가 정하므로 어깨 각이 커도 팔이 어긋나지 않음). 손가락·발가락은 부모 기준 rest.
- **`film --both` 배치**: 시각마다 위 캡슐 256×256 + 아래 FBX 256×256(같은 카메라·디버그 표시). 한 칸 안 좌우 배치는 측면 카메라에서 넘어질 때 두 몸이 겹치고, 반 칸(128 폭)은 쓰러진 몸이 잘린다. 출력은 `film_both*.png`, `--fbx`는 `film_fbx*.png`(캡슐 `film.png`를 덮지 않음).
