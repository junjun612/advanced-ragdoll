## 발견된 문제와 처리
- **손·발 고속 회전**: 충격 후 손·발이 근육 없이 100~150 rad/s로 회전 (근육 켜면 50~70). → 손·발에 각감쇠(수동 관절 마찰)와 관성 배율을 설정으로 넣고, `exploded` 기준 50 rad/s는 유지 (2026-10-26 사람 결정).
- 어깨 스윙 콘 축 = rest 팔 방향(±X). 100°가 애니(최대 78°)와 상처 목표(최대 84°)를 덮음.
- Hips 반경 0.155를 그대로 쓰면 내린 팔과 겹침 → genRagdoll에서 형상 조정.
