# 내일 이야기할 것

밤사이 작업하면서 고민했던 것, 나중에 바꿀 수 있는 것을 모아 둔다. (2026-10-26 밤 작성 시작)

## 고민·확인 거리
1. **성능 예산 초과** — 전신 QP로 캐릭터 1명 스텝당 0.63~0.73ms (예산 0.5ms). 퀄리티 우선이라 그대로 두었다. 웹 데모에서 동시에 몇 명까지 보여 줄지 정하면 그에 맞춰 최적화(KKT 분해 재사용, QP 60Hz 등)를 할 수 있다.
2. **※ 표시 기대값들** — 서술형이던 기대값을 수치로 바꾼 초기값(strength_drop, lean_target, death_limp, ground_writhe 등)과 jitter 기준(≤1/s), 루트 보조 상한(체중 30%). 지금까지는 무리 없이 쓰고 있다.
3. **Kimodo 모델** — 기본 RP-v1.2. SEED-v1.1은 반응이 들쭉날쭉. 비교 문서는 `docs/KIMODO_COMPARE.md`(완성되면).
4. **Kimodo 반응 레퍼런스의 한계** — 텍스트만으로는 밀림 세기를 구분 못 함, 50cm 이상 밀면 계속 뛰어감, "버틴다" 프롬프트로는 절대 안 넘어짐. 넘어짐 경계는 Kimodo로 못 정함 → v0.5b에서 다른 근거가 필요할 수 있다.
5. **강화학습 하이브리드** — v0.4 스텝이 해석적 제어로 사람답게 안 나오면, 균형·스텝 층만 학습 정책으로 바꾸는 안을 검토할지.
